\section*{Reproducibility and Data Availability}
The \dataset{} annotation file, the train/validation/test splits, all model outputs
(11 systems $\times$ 150 test videos), per-video metric vectors, and the scripts that
regenerate every table and figure in this article are released at
\url{https://github.com/harshalDharpure/Crash-X}.
No number in this article requires API access or GPU inference to reproduce from the
released outputs.
